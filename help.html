📁 제이엘 인트라넷
📲 앱 설치문서함로그인
설치 안내

쓰는 기기·브라우저를 고르세요. PC는 확장프로그램(작은 창 + 알림), 휴대폰은 홈 화면 앱으로 쓰면 편합니다.

💻 크롬 — 확장프로그램 (메신저처럼 작은 창)

  1. ⬇️ 설치 파일 받기 (extension.zip) → 받은 파일을 오른쪽 클릭 → 압축 풀기
    jl-intranet-extension 폴더가 생깁니다. 지우지 말고 문서 폴더 등에 그대로 두세요.
  2. 주소창에 chrome://extensions 입력 → Enter
  3. 오른쪽 위 개발자 모드 스위치 켜기
  4. 왼쪽 위 압축해제된 확장 프로그램을 로드합니다 → 1번의 jl-intranet-extension 폴더 선택
  5. 주소창 오른쪽 🧩 퍼즐 아이콘 → "제이엘 인트라넷" 옆 📌 핀 누르기
  6. 작은 창이 뜨면 로그인 → 위쪽 🔔 알림 켜기

✔ 툴바 아이콘을 누르면 작은 창이 열리고, 크롬을 켤 때 자동으로 열립니다. 아이콘의 숫자는 내 컨펌 대기 개수입니다.

🐳 네이버 웨일 — 사이드바 (가장 추천)

웨일은 화면 오른쪽 사이드바에 인트라넷을 붙여 둘 수 있어서, 다른 작업을 하면서 메신저처럼 옆에 띄워 쓰기 좋습니다.

  1. 웨일에서 https://kingjin77-rgb.github.io/intranet/ 접속 → 로그인
  2. 화면 오른쪽 끝 사이드바의 맨 아래 ＋ (사이드바 앱 추가) 클릭
    사이드바가 안 보이면: 오른쪽 위 ≡ 메뉴 → 설정 → 사이드바 → "사이드바 표시" 켜기
  3. 현재 페이지 추가 또는 주소 칸에 https://kingjin77-rgb.github.io/intranet/ 입력 → 추가
  4. 이제 사이드바의 📁 아이콘만 누르면 옆에 인트라넷이 열립니다. (로그인 유지)

🐳 웨일 — 확장프로그램 (알림·숫자 배지까지)

  1. ⬇️ 설치 파일 받기 → 압축 풀기 (jl-intranet-extension 폴더는 지우지 말 것)
  2. 주소창에 whale://extensions 입력 → Enter
  3. 오른쪽 위 개발자 모드 켜기
  4. 압축해제된 확장앱을 로드합니다 → jl-intranet-extension 폴더 선택
  5. 주소창 오른쪽 확장앱 아이콘에서 "제이엘 인트라넷"을 고정
  6. 작은 창이 뜨면 로그인 → 🔔 알림 켜기

💻 마이크로소프트 엣지 — 확장프로그램

  1. ⬇️ 설치 파일 받기 → 압축 풀기 (폴더는 지우지 말 것)
  2. 주소창에 edge://extensions 입력 → Enter
  3. 왼쪽(또는 아래) 개발자 모드 켜기
  4. 압축을 푼 항목 로드 → jl-intranet-extension 폴더 선택
  5. 주소창 오른쪽 퍼즐 아이콘 → "제이엘 인트라넷" 옆 👁 툴바에 표시
  6. 작은 창이 뜨면 로그인 → 🔔 알림 켜기

✔ 엣지는 사이드바에도 붙일 수 있습니다: 오른쪽 사이드바의 ＋ → 현재 페이지 추가.

📱 아이폰 — 홈 화면 앱

📲 그림 보며 설치하기 (휴대폰에서 누르세요)

  1. Safari로 https://kingjin77-rgb.github.io/intranet/ 접속
    카톡에서 열었다면 오른쪽 아래 ⋯ → Safari로 열기 먼저
  2. 아래 가운데 공유 버튼(⬆︎) → 홈 화면에 추가 → 추가
  3. 홈 화면의 인트라넷 아이콘으로 열고 로그인 (처음 한 번)

✔ 홈 화면 앱은 Safari와 로그인이 따로라서 앱에서 한 번 더 로그인해야 합니다. 비밀번호를 정해 두면 간단합니다.

🔔 휴대폰 알림 받기: 홈 화면 앱으로 연 뒤 위쪽 🔔 알림 켜기 → 허용. 아이폰은 iOS 16.4 이상, 홈 화면 앱에서만 알림이 옵니다.

📱 안드로이드 — 홈 화면 앱

📲 그림 보며 설치하기 (휴대폰에서 누르세요)

  1. 크롬으로 https://kingjin77-rgb.github.io/intranet/ 접속
    카톡에서 열었다면 오른쪽 위 ⋮ → 다른 브라우저로 열기 먼저
  2. 화면 아래 뜨는 설치 버튼 누르기
    안 뜨면 오른쪽 위 ⋮ → 앱 설치 (또는 홈 화면에 추가)
  3. 삼성 인터넷: 아래 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면
  4. 네이버 웨일 앱: 아래 ≡ 메뉴 → 홈 화면에 추가

✔ 앱 아이콘에 내 컨펌 대기 개수가 숫자로 표시됩니다(지원 기기).

🔔 휴대폰 알림 받기: 앱을 연 뒤 위쪽 🔔 알림 켜기 → 허용. 앱을 꺼 둬도 컨펌 차례·업무 지시·공지가 알림으로 옵니다.

🔑 처음 로그인 · 비밀번호 정하기

  1. 관리자에게 이메일 등록을 요청 (직원관리에서 등록해야 로그인 가능)
  2. 로그인 화면에서 ✉️ 이메일 코드 → 이메일 입력 → 메일로 온 6자리 코드 입력
  3. 로그인되면 비밀번호 설정 창이 뜹니다 → 8자 이상으로 정하기
  4. 다음부터는 🔑 비밀번호 탭에서 이메일 + 비밀번호로 바로 로그인

✔ 비밀번호를 잊으면 이메일 코드로 들어와서 위쪽 👤 내 이름을 눌러 새로 정하면 됩니다.
