# 사내 미니 인트라넷

카톡에 제안서 파일을 올리는 대신 **문서 링크만** 공유하고, 확인·의견·컨펌는 인트라넷에 남기는 작은 웹앱입니다.

| 기능 | 설명 |
|---|---|
| 문서 공유 | PDF·워드·엑셀·PPT·한글·이미지 업로드 (50MB까지). PDF·사진·워드(.docx)·엑셀(.xlsx)은 바로 보기 |
| 열람 확인 | 누가 언제 몇 번 봤는지, 아직 안 본 사람은 누구인지. 미열람자 독촉 문구 복사 |
| 코멘트 | 문서별 의견 (페이지 번호 지정 가능), 실시간 반영 |
| 순차 컨펌 | 작성자가 컨펌 순서 지정 → 차례대로 컨펌/반려 (반려 시 사유 필수) |
| 카톡 연동 | "카톡 공유용 링크 복사" 버튼 → 카톡방에 붙여넣기 |
| 직원관리 | 관리자가 등록한 이메일만 로그인 가능. 퇴사자는 비활성화 |
| 사건 | 문서·양식·일정·비용을 사건(현장) 단위로 묶어 보기, 진행/종결 관리 |
| 일정 | 기일·마감·미팅 달력, D-day, 전날·당일 PC 알림 |
| 수정본 | 반려되면 "수정본 올리기"로 v2·v3 재상신, 이전 버전·코멘트 보존 |
| 양식 컨펌 | 파일 없이 기안서·지급품의서·출장신청서로 컨펌, 사건별 비용 합계 |
| 로그인 | 처음만 이메일 코드, 이후 이메일+비밀번호 |

구성: GitHub Pages(무료 호스팅) + [Supabase](https://supabase.com) 무료 플랜(DB·로그인·파일 저장). 서버는 따로 필요 없습니다.

```
./          index.html(문서함) doc.html(문서 상세) upload.html login.html admin.html app.js style.css config.js
supabase/   schema.sql (DB 테이블·보안 정책·컨펌 로직)
```

## 설치 (약 20분, 한 번만)

### 1. Supabase 프로젝트 만들기
1. https://supabase.com 가입 → **New project**
2. Region: **Northeast Asia (Seoul)** 선택, DB 비밀번호는 아무거나 저장해 둠

### 2. DB 만들기
1. 왼쪽 메뉴 **SQL Editor** → New query
2. `supabase/schema.sql` 내용을 통째로 붙여넣기
3. 맨 아래 **7번 첫 관리자 등록** 부분의 주석(`--`)을 지우고 본인 이메일·이름으로 바꾸기
4. **Run** — `Success` 가 나오면 완료
5. 이어서 `supabase/migrations/002_v2.sql` 도 같은 방법으로 붙여넣고 **Run** (사건·일정·수정본·양식 기능)

### 3. 로그인 메일 설정
1. **Authentication → Sign In / Providers → Email**: Enable Email provider 켜기, *Confirm email* 켜기
2. **Authentication → Email Templates → Magic Link** 본문을 아래처럼 바꾸기 (6자리 코드가 메일에 나오게)
   ```html
   <h2>사내 인트라넷 로그인</h2>
   <p>인증 코드: <b style="font-size:24px">{{ .Token }}</b></p>
   <p>또는 <a href="{{ .ConfirmationURL }}">여기를 눌러 로그인</a></p>
   ```
   **Confirm signup** 템플릿도 같은 내용으로 바꾸세요 (처음 로그인하는 직원은 이 메일을 받습니다).
3. **Authentication → URL Configuration**
   - Site URL: `https://kingjin77-rgb.github.io/intranet/login.html`
   - Redirect URLs 에도 같은 주소 추가
4. ⚠️ **메일 발송 서버(SMTP) 연결 — 필수**
   Supabase 기본 메일은 Supabase 팀 멤버에게만, 시간당 몇 통만 보내집니다. 직원들이 쓰려면
   **Authentication → Emails → SMTP Settings** 에서 직접 메일 서버를 연결해야 합니다.
   - 간단한 방법: [Resend](https://resend.com) 무료(하루 100통) 가입 → SMTP 정보 입력
   - 또는 회사 Gmail/Google Workspace: 앱 비밀번호 발급 후 `smtp.gmail.com:465` 입력

### 4. 사이트에 Supabase 연결
1. **Project Settings → API** 에서 `Project URL` 과 `anon public` 키 복사
2. `config.js` 에 붙여넣고 회사 이름도 수정 → 커밋
   (anon 키는 공개돼도 되는 키입니다. **service_role 키는 절대 넣지 마세요**)

### 5. GitHub Pages 켜기
1. GitHub 저장소 → **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main` / `(root)` → Save
2. 1~2분 뒤 `https://kingjin77-rgb.github.io/intranet/` 접속

### 6. 직원 등록
1. 관리자 계정으로 로그인 → **직원관리** → 이메일·이름·부서 입력해서 등록
2. **초대 안내 문구 복사** → 회사 카톡방에 붙여넣기

## 앱으로 설치하기 (휴대폰 홈 화면)

앱스토어 없이 홈 화면에 아이콘으로 설치됩니다. 주소창 없이 앱처럼 열리고, 로그인도 유지됩니다.

| 기기 | 방법 |
|---|---|
| 아이폰 | **Safari**로 https://kingjin77-rgb.github.io/intranet/ 접속 → 아래 **공유 버튼(⬆︎)** → **홈 화면에 추가** |
| 안드로이드 | **크롬**으로 접속 → 화면 아래 **설치** 버튼 (안 보이면 오른쪽 위 ⋮ → **앱 설치** 또는 **홈 화면에 추가**) |
| PC (크롬·엣지) | 주소창 오른쪽 **설치 아이콘(⊕)** 클릭 |

- 카톡 안에서 연 화면에서는 설치가 안 됩니다. 카톡 메뉴에서 **Safari/다른 브라우저로 열기**를 먼저 누르세요.
- 앱에서 처음 로그인할 때는 메일의 **6자리 코드**를 입력하세요. 메일 링크를 누르면 앱이 아닌 브라우저에서 로그인됩니다.
- 안드로이드·PC에서는 앱 아이콘에 **내 컨펌 대기 개수**가 숫자로 표시됩니다(지원 기기만).
- 카톡으로 받은 문서 링크는 카톡 브라우저에서 열립니다. 앱에서 보려면 앱을 열고 **문서함**에서 찾으면 됩니다.

## v5.1 반려는 그 사람만

- 컨펌자 중 한 명이 반려해도 문서 전체가 반려되지 않습니다. 반려한 사람 줄에만 ↩️ 반려가 표시되고, 다른 컨펌자는 그대로 컨펌할 수 있습니다.
- 모두 처리하면 컨펌이 1명이라도 있으면 **컨펌완료**, 전원이 반려했을 때만 **반려**가 됩니다.
- 반려가 있어도(전원 반려된 문서도) **＋ 컨펌자 추가**로 다른 분께 컨펌을 받을 수 있습니다.

**적용**: SQL Editor에서 `supabase/migrations/009_reject.sql` 실행 (005 다음 아무 때나). 예전 규칙으로 '한 명 반려 → 전체 반려'가 된 최신 문서는 다시 컨펌중이 되고, 남은 컨펌자에게 차례 알림이 갑니다.

1. Supabase → **Edge Functions → Deploy a new function → Via Editor** → 이름 `send-push` → `supabase/functions/send-push/index.ts` 내용 붙여넣기 → Deploy
2. 함수 설정에서 **Enforce JWT verification 끄기**
3. **Edge Functions → Secrets** 에 `PUSH_SECRET`(아무 긴 문자열), `VAPID_PUBLIC_KEY`(config.js 의 값), `VAPID_PRIVATE_KEY`(관리자에게 따로 전달된 값), `VAPID_SUBJECT`(`mailto:관리자이메일`) 등록
4. SQL Editor에서 한 줄 실행:
   `insert into public.push_config (url, secret) values ('https://<프로젝트ID>.supabase.co/functions/v1/send-push', '<PUSH_SECRET 과 같은 값>') on conflict (id) do update set url = excluded.url, secret = excluded.secret;`
5. 각 직원은 인트라넷에서 **🔔 알림 켜기** (아이폰은 홈 화면 앱에서)

## v2 업데이트 (사건·일정·수정본·양식) 적용 방법

1. Supabase **SQL Editor**에 `supabase/migrations/002_v2.sql` 을 통째로 붙여넣고 **Run** (여러 번 실행해도 안전)
2. 직원들 화면 위쪽에 "새 버전이 나왔습니다 [지금 업데이트]" 띠가 뜨면 누르기
   - SQL 실행 전에는 사건·일정 메뉴에 "DB 업데이트가 필요합니다" 안내만 나오고, 기존 기능은 그대로 쓸 수 있습니다.
   - 아직 옛 화면을 쓰는 직원도 문서 올리기·컨펌은 계속 됩니다.
3. 다음 배포부터는 `app.js` 의 `APP_VERSION` 과 `version.json` 을 같이 올리면 직원들에게 업데이트 안내가 뜹니다.

## PC에서 메신저처럼 쓰기 (크롬 확장프로그램)

툴바 아이콘을 누르면 인트라넷이 **주소창 없는 작은 창**으로 열립니다. 크롬을 켜면 자동으로 열리고, 아이콘에 **내 컨펌 대기 개수**가 숫자로 표시됩니다.

**설치 (한 번만, 2분)**
1. https://kingjin77-rgb.github.io/intranet/extension.zip 을 내려받아 **압축을 풉니다** (`jl-intranet-extension` 폴더가 생김). 이 폴더는 지우지 말고 그대로 두세요.
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 1번에서 푼 `jl-intranet-extension` 폴더 선택
5. 주소창 오른쪽 **퍼즐 아이콘(🧩)** → "제이엘 인트라넷" 옆 **핀(📌)** 눌러 툴바에 고정
6. 작은 창이 뜨면 로그인 (처음 한 번만) → 위쪽 **🔔 알림 켜기** 누르기

**쓰는 법**
- 툴바 아이콘 클릭 → 작은 창이 열림 (이미 열려 있으면 앞으로 나옴)
- 창 크기·위치를 조절해 두면 다음에도 그대로 열림
- 창이 열려 있는 동안 1분마다 확인해서 **새 문서·내 컨펌 차례·코멘트·열람 확인·컨펌 결과**를 PC 알림으로 띄움 (알림 누르면 그 문서로 이동)
- 크롬이 꺼져 있으면 알림이 오지 않습니다. PC 켤 때 크롬도 자동 실행하려면: 크롬 설정 → 시작 그룹 또는 Windows 시작프로그램에 크롬 추가
- 엣지(Edge)에서도 같은 방법으로 설치됩니다 (`edge://extensions`, "압축을 푼 항목 로드")

> 직원이 많아져서 설치가 번거로우면 크롬 웹스토어에 "비공개"로 올리면(개발자 등록비 5달러 1회) 링크 한 번으로 설치됩니다.

## 사용 흐름

1. 작성자: **＋ 올리기** → 파일·제목·컨펌 순서 지정 → 올리기 → **카톡 공유용 링크 복사** → 카톡방에 붙여넣기
2. 직원: 카톡 링크 클릭 → (첫 1회 로그인) → 문서 확인 → 자동으로 열람 기록됨 → 의견 남기기
3. 컨펌자: 문서함의 **내 컨펌 대기** 탭 또는 링크 → 컨펌/반려
4. 작성자: 열람 현황에서 **미열람자 독촉 메시지 복사** → 카톡방에 붙여넣기

팁
- PPT·한글은 미리보기가 안 됩니다. **PDF로 저장해서** 올리면 휴대폰에서도 바로 보입니다.
- 워드·엑셀 미리보기는 이 브라우저 안에서 직접 그립니다(파일이 외부로 나가지 않음). 복잡한 서식·차트는 다르게 보일 수 있으니 정확히 봐야 하면 다운로드하세요.
- 카톡 안에서 링크를 열면 메일 링크로는 로그인이 안 되니, **메일의 6자리 코드**를 입력하세요. 한 번 로그인하면 계속 유지됩니다.
- 반려된 문서는 수정본을 새로 올리면 됩니다 (제목에 v2 등 표기).

## 알아둘 점
- Supabase 무료 플랜: DB 500MB, 파일 1GB, 파일당 50MB. 1주일간 접속이 없으면 프로젝트가 일시정지되며, 대시보드에서 다시 켤 수 있습니다.
- 파일은 비공개 저장소에 있고, 로그인한 직원에게만 1시간짜리 임시 주소로 열립니다. 링크가 외부에 유출돼도 로그인 없이는 볼 수 없습니다.
- 컨펌 순서·권한은 DB 함수(`act_on_step`)가 검사하므로 화면을 조작해도 남의 차례에 컨펌할 수 없습니다.
- 카톡 미리보기에는 모든 문서가 같은 제목("문서 확인 요청")으로 보입니다. 실제 제목은 복사되는 문구에 들어갑니다.
